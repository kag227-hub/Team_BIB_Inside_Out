Methodology

Each scenario has a gain and a loss version for the same fictional stock. We compare sell decisions within the same persona, scenario and model. The reported gap is the gain sell rate minus the loss sell rate, in percentage points, using only pairs with two valid choices. Ratings are summarized separately.

Each emotion and prompt-arm cell has only three pairs. The demo does not report confidence intervals or establish a behavioral effect. Project repository

Results

Positive gaps mean more sell decisions on gains. The neutral control appears as its own row.
